## Ejecutar localmente

No requiere instalación de dependencias. Abre `index.html` en el navegador o ejecuta un servidor estático desde esta carpeta:

```bash
python -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Publicar en GitHub Pages

1. Sube `index.html`, `styles.css`, `script.js` y `README.md` a la rama `main`.
2. En GitHub, abre **Settings > Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/ (root)`.
5. Guarda los cambios y espera a que GitHub genere la URL pública.
